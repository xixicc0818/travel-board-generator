# Travel Board Generator — MVP Product Spec

## Product promise
From messy bookings to one travel-ready Trello board.

## Core user journey
1. Paste or upload trip information
2. System structures the information
3. User previews and fixes the structure
4. User connects Trello
5. User pays once per trip
6. System creates the board
7. User opens it in Trello

## Board schema
### Before You Go
- Flight & Transportation
- Accommodation
- Reservations
- Connectivity / eSIM
- Insurance
- Important reminders

### Day lists
One Trello list per travel day. Each event becomes a separate card.

## MVP commercial model
- Preview: free
- Generate Trello Board: NT$99 per trip
- No subscription at launch

## Product boundary
This is an organizer/exporter, not an AI travel planner.
