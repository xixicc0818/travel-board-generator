# Travel Board Generator v0.1

Turn scattered travel information into a structured Trello board.

## v0.1
- Paste raw travel info
- Preview the board structure
- Connect Trello
- Generate a real board, lists and cards

## Not included yet
- Payment
- AI parser
- File / screenshot parsing
- Saved trips
- Travel planning or recommendations

## Local setup
1. Copy `.env.example` to `.env.local`
2. Add your Trello API key
3. Run `npm install`
4. Run `npm run dev`
